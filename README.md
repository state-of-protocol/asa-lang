# ASA - Bahasa Pengaturcaraan Abadi

**ASA** ialah bahasa pengaturcaraan sistem yang lahir daripada keinginan untuk **kebebasan mutlak**. Ia sumber terbuka selama-lamanya, tanpa pemilikan, tanpa yuran, tanpa sekatan.

> "ASA bukan milik sesiapa. Ia wujud."

## Prinsip
- **Domain Awam**: ASA dilesenkan di bawah CC0. Tiada hak cipta.
- **Self-Hosting**: Pengkompil ASA akan ditulis dalam ASA sendiri.
- **Primitif Terbina Dalam**: Pangkalan data, perayau, kecerdasan buatan — semuanya dalam runtime.
- **Kekal**: Kod yang ditulis hari ini akan berjalan selama-lamanya.

## Status Semasa
Pengkompil permulaan (dalam Rust) sedang dibangunkan. Ia akan menterjemah ASA kepada kod C sehingga pengkompil ASA sendiri siap.
